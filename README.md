# WhatsApp Sticker Bot

A simple WhatsApp bot that converts images, videos, and GIFs into stickers.

## Prerequisites

- Node.js installed
- A WhatsApp account on a mobile device

## Installation

1.  Clone the repository or download the source code.
2.  Install dependencies:
    ```bash
    npm install
    ```

## Usage

1.  Start the bot:
    ```bash
    npm start
    ```
2.  A QR code will appear in the terminal. Scan it with your WhatsApp app (Linked Devices).
3.  Once connected, send any image, video, or GIF to the bot.
4.  The bot will reply with a sticker.

## Development

-   Run `npm run build` to compile TypeScript to JavaScript.
